# 로드뷰 (RoadView)

2종 보통 면허를 위한 **1인칭 도로주행 연습** 웹앱입니다. 운전석 시점으로 시내 도로와 장내기능을 연습하고, 휴대폰 브라우저에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 코스

- **도심 도로주행** — 신호등, 횡단보도, 제한속도, 경로 안내, 감점
- **장내기능** — 경사로 3초 정지, S자 코스, 직각주차
- **시험 모드** — 같은 시내 코스를 채점합니다. 70점 합격, 신호위반·충돌은 실격

## 조작

| 동작 | 키보드 | 터치 |
|------|--------|------|
| 가속 | `W` / ↑ | 오른쪽 가속 페달 |
| 제동 | `S` / ↓ / Space | 오른쪽 제동 페달 |
| 좌·우 조향 | `A` `D` / ← → | 왼쪽 핸들 |
| 방향지시등 | `Z` 좌 / `C` 우 / `X` 해제 | 좌·우 버튼 |
| 후진 / 전진 | `Q` 후진 / `E` 전진 | `R` / `D` 토글 |
| 일시정지 | `Esc` / `P` | 일시정지 버튼 |

후진 기어에서는 후방 카메라가 켜집니다.

## 실행

Node 22가 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 개발 서버 주소로 접속하세요. 빌드는 `npm run build`입니다.

## 안드로이드

Chrome에서 사이트를 연 뒤 **홈 화면에 추가**하면 전체 화면에 가깝게 실행됩니다.
